授權注意事項

09 / LICENSE
  • Copernicus（Sentinel-1/2） — 免費開放含商業使用，僅需標註來源（"Contains modified Copernicus Sentinel data"）。無實質限制。
  • 政府開放資料（CWA、DEM、水利署、SEGIS、TDX 等） — 政府資料開放授權條款第一版，相容 CC BY 4.0，標註來源即可。
  • Global Fishing Watch — API 對非商業研究免費，需同意其資料使用條款；成果發表需標註。競賽用途屬研究展示，符合範圍，但若團隊日後商業化需另談授權。
  • AISHub — 互惠義務：持續貢獻接收資料才保有存取權；接收站下線即失效，demo 前留意。
  • TeleGeography 海纜圖 — CC BY-SA：share-alike 具傳染性，衍生圖層需以相同授權釋出。建議海纜圖層獨立存放、不與其他資料混製衍生檔，避免授權糾纏。
  • OpenStreetMap — ODbL：衍生資料庫需開放，地圖成果標註 © OpenStreetMap contributors。
  • 媒體報導 — 僅做分析與連結引用，不重製全文入庫；事件卡片放摘要與原文連結。
  • 福衛影像 — 依 TASA 申請條款，通常限申請用途，不得再散布；報告中只放衍生分析結果。
提案書寫法建議 直接附上這張授權對照，展示團隊對開源授權的成熟理解——「開源」是本競賽的命題關鍵字，多數隊伍只會列資料清單，能講清楚 share-alike 傳染性與互惠義務的隊伍極少。

# people

每位成員一個資料夾，內含自己的 `PROGRESS.md`。

```
people/
├── cindy/PROGRESS.md
├── <成員 B>/PROGRESS.md
└── <成員 C>/PROGRESS.md
```

## 約定

見 `../SCHEDULE.md`：

- 每週同步進度回報：**星期一早上 9:00 前**
- 各自在自己的資料夾維護 `PROGRESS.md`
- 三欄格式：做了／卡住／下週

## 怎麼寫

**「卡住」那欄是重點。** 大家通常只寫做了什麼，但真正需要在週會上處理的
是卡住的事。卡住的項目請寫清楚是「技術問題」「等外部回覆」還是
「需要團隊決定」——前兩者週會上講一下就好，第三種要排時間討論。

**做了的部分寫結果，不寫過程。** 「完成座標轉換，75 筆全數落點正確」
比「研究了 TWD97 半天」有用。有數字就放數字。

**下週的項目要具體到可以打勾。** 「處理影像」不算，「寫完 cwa.py 的
地震報告查詢並通過測試」才算。
